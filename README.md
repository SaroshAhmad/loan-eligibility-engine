# Loan Eligibility Engine

A rule-based loan decisioning system built in Java 21.

Simulates how banks evaluate loan applications using a weighted rule engine,
custom exception handling, JDBC persistence, and audit logging.

## Tech Stack
- Java 21
- Maven
- H2 (embedded database)
- JDBC
- JUnit 5

## Project Status
In active development — built as a structured backend learning project.
